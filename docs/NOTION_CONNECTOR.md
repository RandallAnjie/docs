# Notion 连接

更新时间：2026-11-25 UTC

Rdocs 可以连接一个 Notion 工作区：把 Notion 的页面和数据库导入 Rdocs，或让数据库自动化把记录写进 Notion 数据库。

## 连接

1. 在 Notion 的 [集成管理](https://www.notion.so/profile/integrations) 新建一个「内部」集成，复制密钥（`ntn_…`）。
2. 在要导入或写入的 Notion 页面、数据库右上角「···」→「连接」，选择这个集成。Notion 只把明确连接的内容开放给集成。
3. Rdocs 工作区所有者或管理员在「设置 → Notion」粘贴密钥。Rdocs 先调用 Notion `users/me` 校验，再用 AES-GCM 加密保存（密钥由 Worker 的 `COLLAB_TICKET_SECRET` 派生），之后不再返回明文。

每个组织只保存一个连接；工作区成员都能看到连接状态、搜索已连接的内容并导入到自己能编辑的空间。断开后，写入 Notion 的自动化会失败，已导入的内容不受影响。

## 导入

- **数据库**：按字段类型映射为 Rdocs 字段，选项会一起带上；每次最多导入 500 条记录，不触发 Rdocs 自动化。

  | Notion                                                            | Rdocs                    |
  | ----------------------------------------------------------------- | ------------------------ |
  | 标题、文本、数字、单选、状态、多选、日期、复选框、URL、邮箱、电话 | 同类型字段               |
  | 创建时间、最后编辑时间                                            | 日期（含时间）           |
  | 人员、文件、关联、公式、汇总、创建者、编辑者、唯一 ID             | 文本（保留当时的显示值） |
  | 按钮、验证等                                                      | 跳过，并在结果中列出     |

- **页面**：正文转换为 Markdown 后导入，支持标题、段落、列表、待办、折叠、引用、提示框、代码、公式、分割线、表格、书签和外部图片；最多读取 3 层嵌套、1000 个块。Notion 托管的文件和图片链接约 1 小时后失效，因此导入为带提示的链接，需要手动重新上传。子页面和子数据库只保留标题，需单独导入。

## 自动化写入 Notion

数据库自动化的「写入 Notion 数据库」动作会在指定 Notion 数据库里新建一页。保存时 Rdocs 会读取该数据库的字段，确认每个映射的字段存在且可写（标题、文本、数字、单选、状态、多选、日期、复选框、URL、邮箱、电话）；字段值可以复制触发记录的字段，或者填写固定值。动作以组织的 Notion 连接执行，运行结果和失败原因记录在自动化运行日志中。

## 限制

- 使用 Notion API 版本 `2022-06-28`。
- 导入是一次性复制，不会持续双向同步。
- Notion 的人员无法对应到 Rdocs 成员，导入为姓名或邮箱文本。
