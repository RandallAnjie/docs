# Rdocs × Notion 功能等价实施基线（2026）

更新时间：2026-08-15  
状态：实施中  
范围：Notion Free、Plus、Business、Enterprise 的产品能力，以及当前公开的 Notion AI、Projects、Sites、Forms、Charts、Automations、API 与企业管理能力。

## 1. “完整复刻”的定义

Rdocs 的目标是实现与 Notion 功能等价、可互操作且拥有自身品牌的产品，而不是复制 Notion 的商标、文案、私有代码或不可公开验证的内部实现。验收以用户能否完成同一类任务为准，不以像素级复制或相同接口命名为准。

以下产品决策优先于 Notion 的当前行为：

- 登录以设备密钥（Passkey/WebAuthn）为默认且首要方式，不接入 GitHub OAuth。
- 不提供可编辑“访客”身份。加入租户后是正式成员；公开链接和未登录用户只能读取被明确发布的内容。
- 所有 Free/Plus/Business/Enterprise 功能都进入 Rdocs 的产品范围。是否收费是后续商业配置，不用功能阉割驱动架构。
- 不修改 RandallFlare 平台代码。应用缺少的绑定或平台能力会形成单独的外部依赖报告。

## 4. 实施顺序与依赖

### 阶段 A：编辑器与数据库基础

1. 数据库、属性、行页面、单元格、视图的 D1 schema。
2. 所有 API 都从当前用户反查数据库所属页面，并复用页面 ACL。
3. 基础属性、公式安全求值、关系/汇总、筛选/排序/分组。
4. 表格、看板、日历、列表、画廊、时间线视图。
5. 编辑器块菜单、块转换/拖拽、分栏、折叠块、Callout、目录、公式、书签、安全嵌入、专用私有文件/音频/视频块、动态面包屑及基础页面按钮已完成。
6. 跨页同步块的独立资源、既有多块转换、复制引用、权限过滤的位置列表、单个/全部取消同步、原始块级联删除、实时协作、自动保存、离线/HTTP 恢复及“原始页 + 当前页”双重权限已完成；级联删除会在引用位置留下操作绑定占位，30 天内可整体恢复且保留删除后的并发编辑。删除/恢复采用有界并发、租约、操作 ID 和幂等重试，转换失败会清理孤儿资源；跨组织同步仍不开放。
7. 页面链接块、双页面鉴权预览、服务端反向链接投影、权限裁剪的所有更新、搜索排序/筛选/精确短语及浏览器命令面板已完成；外部应用实时预览仍依赖后续连接器能力。
8. 页面通知级别、评论自动订阅、权限感知的内容更新投递、事件去重、按页面/评论线程聚合、线程深链、整组状态操作和收件箱内直接回复已完成。页面提醒、正文 `@remind`/`@提醒` 协同节点和数据库日期属性提醒均支持自己/其他正式成员、时区、提前量、修改、取消和来源删除联动；继续补数据库日期时间/范围体验、邮件/系统推送，以及用户完全离线时依赖平台 cron 的准点投递。Notion 官方当前同样不支持原生重复提醒。
9. 块菜单可复制基于 Yjs RelativePosition 的稳定块链接，协同编辑导致前文位移后仍能解析并定位高亮；资料库可在当前租户内多选页面并批量收藏、取消收藏、移动、修改图标或移入回收站，回收站支持批量恢复。每项操作仍逐页经过服务端 ACL，所选父子页面会折叠为一次子树结构操作。
10. 原始同步块级联删除改为可恢复 saga：每个引用位置写入相同删除操作 ID 的占位块，引用页清单保留 30 天；恢复时重新校验所有页面的编辑、锁定和协作状态，只替换匹配操作的占位，不回滚其他内容。Notion 官方说明超过 10 个副本时 Undo 无法恢复全部副本，Rdocs 在此项提供更强的数据恢复保证。

验收：不同租户不可枚举或引用对方数据库；viewer 只能读取；editor 可改行和内容；space_admin 可改 schema/视图/权限；数据行可作为普通页面打开并协作编辑。

### 阶段 B：结构化工作流

1. 项目/任务/Sprint/依赖/子任务预设。
2. 表单和公开提交令牌。
3. 图表、仪表盘和导出。
4. 页面/数据库按钮、自动化、Webhook 动作与运行日志。

验收：数据库同一数据源能同时以多个视图呈现；表单提交没有编辑权限；自动化可幂等重放且每次运行可审计。

### 阶段 C：发布、搜索与生态

1. Sites 普通页面发布、SEO、路径、主题、导航、站内搜索、robots/sitemap 与匿名聚合分析已完成；结构化数据库公开视图和正文预渲染继续实施。
2. 自定义域名所有权状态与证书状态；实际域名绑定只调用 RandallFlare 已提供的应用接口。
3. 全域搜索、反向链接、附件文字索引。
4. 公共 API、OAuth 2.1 集成授权、Webhook、连接器与模板目录。

验收：未发布的页面不进入公开索引；站点访问者永不获得编辑通道；API token 权限不能超过安装者授权范围。

### 阶段 D：AI 与企业治理

1. 权限感知 RAG、写作、数据库 Autofill、研究模式和引用。
2. 会议录音上传/转写/总结、行动项回写；实时录音需浏览器明确授权。
3. Agent/技能/MCP 工具授权、人工确认和运行审计。
4. SAML、SCIM、域验证、受管用户、会话策略。
5. 保留、法务保全、管理内容搜索、分析、SIEM/DLP 出口和网络策略。

验收：AI 检索结果不能越过页面/行权限；企业可配置不留存；管理动作、Agent 工具调用和导出都有审计证据。

### 阶段 E：离线、跨端与大规模可靠性

1. PWA、离线页面选择、最近/收藏预取、离线附件策略。
2. 批量导入/导出、长任务、失败恢复和进度通知。
3. 压测、辅助功能、键盘操作、国际化、移动端完整交互。
4. 桌面/移动壳、深链、系统分享与通知。

## 5. 权限不变量

```text
组织成员资格
  └─ 空间 ACL（none / viewer / commenter / editor / space_admin）
      └─ 页面 ACL（inherit / restricted + 显式拒绝优先）
          └─ 数据库 schema / view / row / cell / attachment / AI retrieval
```

- `none` 永远优先于组或组织授予的更高权限。
- legacy guest 永远被封顶为 viewer；新系统不再创建 guest。
- 公开分享和 Site 访问者没有成员身份，不能获得写 ticket。
- 同步块必须同时通过原始页面和当前容器页面权限；任一侧撤权、锁定、停用或租户/空间/组权限变化都提升同步资源 ACL 并关闭已打开连接。
- 数据库行级规则只能收窄页面权限，不能提升页面权限。
- 公式、汇总、搜索、导出、AI、Webhook payload 都必须应用相同的访问裁剪。
- 任何带副作用的集成和 Agent 动作必须有显式 capability，且不能借安装者权限绕过最终用户可见范围。

## 6. 外部依赖（不阻断应用内实现）

下列能力可先完成代码、配置模型和测试，但正式启用需要租户或平台提供外部材料：

- AI/转写：模型提供方 endpoint、model、credential 和数据留存策略。
- SAML：IdP metadata、证书、entity ID、ACS 域名。
- SCIM：企业管理员生成的 bearer token 和 IdP 配置。
- 自定义域名：DNS 所有权验证及 RandallFlare 已支持的自定义主机名/证书接口。
- SIEM/DLP：客户 endpoint、签名密钥、字段映射和传输要求。
- Google/Microsoft/Slack 等连接器：第三方应用注册和 OAuth client 凭据。

这些依赖不会导致 Rdocs 私自修改 RandallFlare。若 RandallFlare 没有某项必要能力，会输出明确的接口、绑定、失败模式和最小补充要求。

## 7. 完成标准

“已完成 Notion 功能等价”只有在以下条件同时满足时才能标记：

1. 本文矩阵不再存在 `缺失` 或未说明的 `部分`。
2. 每类能力都有正常、无权限、跨租户、并发、离线或失败恢复测试。
3. 核心路径通过桌面和移动浏览器端到端验收，键盘与屏幕阅读器可用。
